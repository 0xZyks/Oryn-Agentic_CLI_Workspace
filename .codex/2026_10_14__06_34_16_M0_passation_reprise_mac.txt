REPRISE MAC — COMMANDES PRÉVUES, NON EXÉCUTÉES ICI
Prérequis : SDK .NET 10 (global.json 10.0.100 + latestFeature ; Linux de cette
session utilisait 10.0.401), terminal interactif, accès NuGet au premier restore.
Depuis le dépôt actualisé :
  dotnet restore Oryn.slnx
  dotnet build Oryn.slnx --no-restore
  dotnet run --project src/Oryn.Cli --no-build
Pour tester dans un répertoire projet précis, se référer à README.md/CLI help.
Vérifications conseillées pour cette reprise :
  dotnet test tests/Oryn.App.Tests --no-restore
  dotnet run --project tests/Oryn.Smoke --no-restore
  python3 scripts/keyboard-smoke.py src/Oryn.Cli/bin/Debug/net10.0/oryn
  python3 scripts/visualizer-smoke.py src/Oryn.Cli/bin/Debug/net10.0/oryn
  python3 scripts/component-smoke.py src/Oryn.Cli/bin/Debug/net10.0/oryn
  python3 scripts/chat-smoke.py src/Oryn.Cli/bin/Debug/net10.0/oryn
Python 3 requis pour les suites PTY POSIX. L'application fonctionne depuis le
build, sans installation. Pour une publication autonome sur Apple Silicon :
  dotnet publish src/Oryn.Cli -c Release -r osx-arm64 --self-contained true -o artifacts/osx-arm64
Sur Mac Intel, utiliser osx-x64. Garder les fichiers de publication ensemble.
Les installeurs existants ciblent Linux et Windows ; aucun installeur Mac dédié.

PARTICULARITÉS MAC ET TERMINAL À VÉRIFIER
- Détection écran/Hz auto actuelle : Niri/Linux uniquement. Sur Mac, fallback
  explicite 60 Hz ; ce n'est pas une dépendance à Niri pour démarrer. --fps 144
  permet un réglage manuel, --fps auto revient au mode auto/fallback.
- Les profils utilisateur et réglages du terminal sont hors dépôt ; ils ne
  suivent pas le push. Sans profil de keybindings, défauts chargés normalement.
- Kitty intercepte Ctrl+Tab et Ctrl+Shift+Tab par défaut. Si Kitty est utilisé
  sur Mac et que le focus reste immobile, voir README.md et le script optionnel
  scripts/configure-kitty-shortcuts.py (--dry-run d'abord). Oryn marque sa
  session avec OSC SetUserVar ; les mappings scoped se configurent par machine.
- Les autres terminaux peuvent transmettre différemment Ctrl+Tab et
  Shift/Alt+Enter. Vérifier les touches physiques : les PTY synthétiques
  contournent les raccourcis de l'émulateur. Option/Alt doit parvenir comme Alt
  à l'application. F1–F6 peuvent dépendre du réglage clavier macOS/Fn.
- Win/Command n'est pas directement exposé par cet adaptateur ; Ctrl/Alt ou
  leader Space/F12 sont disponibles. Vérifier UTF-8/Braille et utiliser les
  options --ascii --no-color en cas de capacité terminal limitée.
- Tester démarrage/fermeture, état shell restauré, resize, dock, focus, chats,
