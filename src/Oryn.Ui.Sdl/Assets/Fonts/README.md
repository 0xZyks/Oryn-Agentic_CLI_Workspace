# Bundled Nerd Font symbols

`SymbolsNerdFontMono-Regular.ttf` is the unmodified **Symbols Nerd Font Mono** from Nerd Fonts **v3.4.0**.

- Source: https://github.com/ryanoasis/nerd-fonts/blob/v3.4.0/patched-fonts/NerdFontsSymbolsOnly/SymbolsNerdFontMono-Regular.ttf
- SHA-256: `f0f624d9b474bea1662cf7e862d44aebe1ae1f6c7f9cb7a0ca5d0e5ac9561c60`

- Upstream usage: https://github.com/ryanoasis/nerd-fonts/blob/v3.4.0/patched-fonts/NerdFontsSymbolsOnly/README.md

The font is an embedded resource in Oryn.Ui.Sdl, available offline in builds, publishes and the CLI tool without installing a system font. It supplies missing symbols while keeping the existing monospace text face. Additional Unicode coverage depends on installed system fonts. This is a rendering asset; models receive and return Unicode text, not font files.
